# MoveFit - Frontend

Aplicativo web de academia virtual, projeto da FATEC Zona Sul.

Este repositório contém o **frontend** do MoveFit (TypeScript, desenvolvido no Replit).

## Como o projeto está dividido

- **Frontend (este repositório):** telas do aplicativo, como treinos, agenda, exercícios e perfil.
- **Backend:** API em Java com Spring Boot, em https://github.com/alexandre910/treino_1

O frontend consome a API do backend, que está hospedada na AWS (EC2) e usa um banco MySQL no AWS RDS.

## Tecnologias

- TypeScript
- Replit (edição e publicação)
